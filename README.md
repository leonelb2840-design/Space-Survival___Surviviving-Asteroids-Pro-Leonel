# Asteroids Survival PRO

Un juego de supervivencia estilo **Asteroids** hecho 100% con **HTML5 Canvas + JavaScript puro**, optimizado para **móvil y escritorio**.

¡Sobrevive el mayor tiempo posible destruyendo asteroides, recogiendo power-ups y derrotando al **Boss** cada 1500 puntos!

### 🎮 Características principales

- Controles táctiles completos (arrastrar para mover, tocar para disparar)
- Asteroides que se **dividen** al destruirlos (large → med → small)
- **Power-ups** que caen aleatoriamente:
  - **Multi-shot** (3 balas en abanico)
  - **Rapid fire** (disparo ultra-rápido)
  - **Shield** (invencibilidad temporal + glow dorado)
- **Boss** cada 1500 puntos: asteroide gigante púrpura que dispara balas rojas y tiene barra de vida
- Dificultad progresiva: más asteroides, más rápidos y más peligrosos cuanto más puntos tengas
- Efectos visuales: partículas de explosión, glow en power-ups y balas, trail en fondo
- Interfaz clara: puntos, vidas, contador de asteroides y HP del boss

### 🕹️ Controles

| Acción              | Escritorio (PC)       | Móvil (touch)                  |
|---------------------|------------------------|---------------------------------|
| Mover nave          | WASD o flechas         | Arrastrar dedo                  |
| Disparar            | Clic izquierdo         | Tocar cualquier parte de pantalla |
| Jugar / Reiniciar   | Clic en botón          | Tocar botón o pantalla          |

### 🚀 Cómo jugar

1. Abre `index.html` en tu navegador (Chrome recomendado en móvil)
2. Toca **JUGAR** o cualquier parte de la pantalla
3. ¡Sobrevive! Destruye asteroides, recoge power-ups y derrota al Boss
4. Intenta superar tu propio highscore (no hay guardado aún, pero puedes anotarlo)
